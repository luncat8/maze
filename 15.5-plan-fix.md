Goal: tidy leftover code/comments from the engine splits so the repo is
self-explanatory to a new reader. Code change must NOT alter the user-visible
physics, the on-disk save format, or any test assertion.

Risk policy applied here:
* **No physics edits.** All fixes are behavioural no-ops, comment fixes,
  dead-code removal, or one-line wiring that matches an already-existing
  sibling pattern (e.g. add the same `scheduleFieldRecompute()` that R_metal
  and R_bat already use).
* No tests are added/removed. Test-message typo fix is wording-only.
* Each fix cites the file:line and explains why it cannot regress anything.

### Defer with reason (16-plan scope)

These are the reviewer's other findings, recorded so they don't get lost.
None are touched in this pass because they re-open design decisions:

* **A. Test 11b doesn't discriminate transient vs steady-state.** The settled
  peak scales as `1/α`, so two runs at different α produce peaks exactly in
  the ratio of the α's — which is what an instant Poisson solve also gives.
  Real test: hold α fixed, vary sweep count; expect `peak(5) < peak(50) <
  peak(500)`, monotone toward the asymptote. Out of scope: needs new test
  code + the right tolerance.
* **B. `S` has no `dt` scaling, so α changes force amplitude 4× across the
  slider range.** Needs `MAG_SRC_GAIN_DIFF` + a `dt`-separated step. This is
  the same gap the 16-plan's "Russian critique" flagged; confirmed missing.
  Physics change — out of scope.
* **E. Diffusion has no dipole support.** When `MAG_DIPOLES` is on, switching
  to `'diffusion'` silently drops the magnet↔magnet interaction. Needs either
  a dipole injector for diffusion (with self-subtraction), or a UI hint. Out
  of scope.
* **F. 40-line duplicated publish block** (and `Eb`/`elecP`/`lastEMF`/`lastHeat`
  being computed by both engines despite neither injecting back-EMF).
  Refactor to a shared `magPublishTelemetry(mags, bzAt, opts)`. The reviewer
  is right that this is the highest-value cleanup; defer to a Phase-2 plan
  because it's a real refactor and the 16-plan already lists it.
